# Operationalization Wave 12 — Governed Tests

Wave 12 operationalizes only Increment 13 under CR-013. Verified Tests-specific OPA authorization precedes exact immutable Sandbox/Security/candidate/run reads, governed manifest access, institutional image assurance, and invocation.

Deployment must provide the exact manifest, image, Firecracker-class isolation values, non-secret environment/network scope, sovereign HTTPS runtime, signed-response trust, and request/response bounds. Repository defaults provide none and fail closed.

Every required test must be uniquely discovered, completed, passed, unskipped, and evidenced. The result is independently authorized and appended as immutable tenant-scoped PostgreSQL evidence. Human Review and later stations remain disconnected.
