# Operationalization Wave 08 — Governed Code Generation

Wave 08 operationalizes only the inert Code Generation candidate boundary approved by CR-009. Deployment operators must provide PostgreSQL, signed OPA bundle access, package trust, complete AI Planning and Code Generation runtime profiles, signed prompts, fixed sovereign HTTPS generation/evaluation endpoints, distinct operator identities, pinned public keys, and benchmarked positive safety bounds.

Repository defaults deliberately provide none of those values. A configured call reads and verifies the exact AI Planning, Approved Packages, and `AiPlanning`-stopped delivery-run evidence, obtains exact OPA scope, verifies the signed prompt, re-authorizes every context item, generates only inert content plus exact normalized relative paths, independently evaluates all six criteria, re-authorizes the candidate and paths, and appends immutable PostgreSQL evidence.

No generated content is written, applied, compiled, restored, scanned, executed, committed, deployed, or used to advance workflow. Static Validation remains disconnected.
