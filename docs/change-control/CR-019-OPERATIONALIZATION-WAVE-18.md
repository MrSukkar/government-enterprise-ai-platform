# CR-019 — Operationalization Wave 18: Governed OpenTelemetry Activation

Status: **Approved for Operationalization Wave 18**

Authority: Master Specification; contract: `docs/change-control/CR-001-AMENDMENT-16-OPENTELEMETRY.md`; preceding gate: `docs/operationalization/WAVE_17_ACCEPTANCE.md`.

Decision: **Approved by the repository owner on 2026-09-12 through the active instruction to continue.**

Only Governed OpenTelemetry Activation is authorized: exact accepted Deployment evidence, `Deployment`-stopped run, exact signed OPA scope, immutable signed telemetry profile, strict independent redaction verification, trusted collector activation for traces/metrics/logs, result authorization, and immutable evidence.

No provider, collector, profile, service identity, exporter, endpoint, key, credential, institutional data, sampling value, retention value, numeric bound, or SLO is selected. Automatic Registration, Enterprise Model mutation, workflow advancement, external provisioning, and real external activation remain excluded.
