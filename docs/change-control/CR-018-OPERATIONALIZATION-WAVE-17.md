# CR-018 — Operationalization Wave 17: Governed Sovereign Deployment

Status: **Approved for Operationalization Wave 17**

Authority: Master Specification; contract: `docs/change-control/CR-001-AMENDMENT-15-DEPLOYMENT.md`; preceding gate: `docs/operationalization/WAVE_16_ACCEPTANCE.md`.

Decision: **Approved by the repository owner on 2026-09-12 through the active instruction to continue.**

Only Governed Sovereign Deployment is authorized: exact accepted Artifact evidence, `Artifact`-stopped run, exact signed OPA scope, immutable signed sovereign profile, institutional preflight, one bounded signed provider-neutral deployment invocation, result authorization, and immutable evidence.

No provider, runtime, profile, topology, target, endpoint, key, credential, secret, institutional data, capacity value, numeric bound, or SLO is selected. OpenTelemetry configuration, Automatic Registration, Enterprise Model mutation, workflow advancement, external provisioning, and any real public deployment remain excluded.
