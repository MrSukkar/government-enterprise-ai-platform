# Integration Demo Stage 16 runtime contract

Stage 16 extends the localhost-only synthetic demonstration to Governed Artifact Publication. It binds exact accepted CI/CD evidence and the `CiCd`-stopped run to signed action-specific OPA scope, exact pipeline-output validation, a provider-neutral `IInstitutionalArtifactRegistryGateway`, the existing six-control supply-chain verifier, result authorization, and append-only PostgreSQL evidence.

Deployment operations must provision all Stage 15 inputs outside Git plus `.runtime/integration-demo-stage-16/artifact/seed.sql`, containing the exact `CiCd`-stopped snapshot and pipeline-output manifest. They must configure `Platform:SoftwareFactory:ArtifactRuntime` with a real institutionally approved immutable registry gateway, operator/verifier identities, positive bounds, signing policy, and pinned verification trust. The gateway must bind the exact manifest, source commit, workflow, coordinate `ContainerImage:Platform.Synthetic.Permit.Service:1.0.0`, content digest, registry, repository, and all mandatory controls.

Repository defaults remain empty and fail closed. The demo must never substitute a fake manifest, artifact, registry publication, signature, provenance, SBOM, attestation, verification, gateway response, or successful result. No credential, token, private key, endpoint, trust material, institutional data, artifact, or publication is stored in Git. The receipt records `ArtifactPublished: true`, `RegistryMutated: true`, `SourceMutationOccurred: false`, `DeploymentOccurred: false`, `ProductionEffectOccurred: false`, and `CanAdvance: false`; it cannot deploy, reach Production, or grant workflow authority.
