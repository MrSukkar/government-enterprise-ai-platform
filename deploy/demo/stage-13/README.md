# Integration Demo Stage 13 runtime contract

Stage 13 extends the localhost-only synthetic demonstration to Governed Human Review. It binds the exact accepted Tests, Sandbox, Security, and Code Generation evidence chain to signed action-specific OPA scope, an authenticated human reviewer separated from the delivery-run initiator, the provider-neutral `IHumanReviewAttestationVerifier` sovereign protocol, and atomic append-only PostgreSQL decision evidence.

Deployment operations must provision all Stage 12 inputs outside Git plus the exact delivery-run snapshot stopped at `Tests`, including initiator subject `10000000-0000-0000-0000-000000000012`, through `.runtime/integration-demo-stage-13/human-review/seed.sql`. They must configure `Platform:SoftwareFactory:HumanReviewRuntime` with a real institutionally approved HTTPS attestation endpoint, verifier identity, positive request/response bounds, signature algorithm, and pinned public verification trust. The reviewer signs in as the distinct synthetic human-review identity `10000000-0000-0000-0000-000000000013`. No attestation, private key, credential, institutional data, endpoint, trust material, or successful decision is stored in Git.

The policy scope binds the reviewer, initiator, explicit `Approve` or `Reject` decision, rationale digest, supplied attestation reference, conflict set, optimistic version `-1`, HumanReviewer role, and `human-review-decision` output. OPA authorizes before prerequisite reads. The attestation verifier must independently prove the authenticated human identity, signature validity, non-repudiation, exact decision, and exact review-package digest before the atomic append-only record is accepted.

Repository defaults remain empty and fail closed. The demo must never substitute a fake reviewer, verifier, signature, attestation, decision, or successful result. Same-actor review, missing rationale, absent or mismatched evidence, stale version, unsigned response, invalid trust, or unavailable dependencies fail closed. The receipt records `ProductionEffectOccurred: false` and `CanAdvance: false`; it cannot mutate source, perform Git, trigger CI/CD, reach Production, or grant workflow authority.
