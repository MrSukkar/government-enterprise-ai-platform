# Integration Demo Stage 15 runtime contract

Stage 15 extends the localhost-only synthetic demonstration to Governed CI/CD Execution. It binds the exact signed Git receipt and `Git`-stopped delivery run to signed action-specific OPA scope, an immutable signed workflow definition, an isolated runner policy, a provider-neutral `IInstitutionalCiCdGateway`, result authorization, and append-only PostgreSQL evidence.

Deployment operations must provision all Stage 14 inputs outside Git plus `.runtime/integration-demo-stage-15/cicd/seed.sql`, containing the exact `Git`-stopped run snapshot and immutable workflow definition. They must configure `Platform:SoftwareFactory:CiCdRuntime` with a real institutionally approved HTTPS CI/CD gateway, gateway/operator identities, positive request/response bounds, signature algorithm, and pinned public verification trust. The gateway must bind repository `repository://demo/permit-renewal-service`, the exact signed commit/tree/change-set, workflow `workflow://demo/internal-service/verify-build-attest` version `1.0.0`, pipeline profile `demo-sovereign-cicd`, runner pool `runner-pool://demo/isolated-dotnet10`, and the exact required stages and controls.

The policy permits only `internal-service.cicd.execute` and `cicd-result`. OPA authorizes before checkout, source disclosure, runner allocation, dependency access, or invocation. The signed gateway response must prove ephemeral isolation, default-deny networking, locked dependencies, exact stage/control success, and a non-released manifest with SBOM, checksums, provenance, build attestation, signature, and evidence.

Repository defaults remain empty and fail closed. The demo must never substitute a fake workflow, runner, execution, SBOM, provenance, attestation, signature, output manifest, gateway response, or successful result. No credential, token, private key, endpoint, trust material, institutional data, execution, or output is stored in Git. The receipt records `CiCdTriggered: true`, `SourceMutationOccurred: false`, `ArtifactPublished: false`, `DeploymentOccurred: false`, `ProductionEffectOccurred: false`, and `CanAdvance: false`; it cannot publish an Artifact, deploy, reach Production, or grant workflow authority.
